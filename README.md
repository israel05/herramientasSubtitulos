# Herramientas de Subtitulos

Son dos herramientas para procesar audio.
## Extractor de mp3
La primera es un script de powershell que extrae los mp3 desde los mp4 de un directorio
## Generador de srt
La segunda es un python que usa la CPU para conseguir subtítulos srt a partir de los mp3 anteriores.

### Notas
El script de python esta forzado para usar el modelo más complejo, pero se puede usar uno mas cutre y liviano. Los resultados serán proporcionales
El script de powershell no esta firmado, hay que elegir si firmarlo o hacer la guarrada de cambiar el nivel de seguridad de todo windows "Set-ExecutionPolicy RemoteSigned"
